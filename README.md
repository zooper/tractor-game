# Backlot Loader

A low-poly 3D earthmoving and snow-plowing sandbox that runs in the browser. Open `index.html` in a modern browser; three.js loads from cdnjs.

## Jobs

- **Dirt lot**: an articulated wheel loader and a tracked excavator. Load the dump truck, feed the hopper and conveyor, cut the staked pad to grade, and dig a trench so the pipe can be laid and backfilled.
- **Snow day · Paulus Hook, Jersey City**: plow the real streets around Liberty Towers. Streets, buildings and the Hudson-Bergen Light Rail come from OpenStreetMap. Loader with plow blade or bucket, a salt spreader truck, a snow dump truck, parked cars, moving traffic, streetlights and day/dusk/night.

## Controls

| Keys | Action |
|---|---|
| W / S | drive |
| 1 / 2 / 3 / 4 | gear (each machine keeps its own) |
| A / D | steer / turn on tracks |
| I / K | raise / lower boom |
| J / L | curl / dump bucket, angle the plow, salt fan width |
| B | swap bucket / plow blade, salt spreader on/off |
| X | switch machine |
| Q / E, R / F | excavator swing, stick out / in |
| C | cab view (mirrors; Z / V to look left / right) |
| T | day / dusk / night |
| P | full map (a minimap is always in the corner) |
| G | grade / unplowed view |
| M | sound |
| N N | new site |

Map data © OpenStreetMap contributors (ODbL).
